## 🌟 المميزات الرئيسية

- **واجهة مستخدم بطابع Creality Slicer / OrcaSlicer الداكن**: ألوان مريحة للمصممين مع لوحات تحكم مرنة وسريعة.
- **محرك Slicer ثلاثي الأبعاد متقدم (Three.js)**: معاينة حية للمجسمات، التحكم في أبعاد لوحة الطباعة (Bed Plate)، حذف وإضافة لوحات الطباعة.
- **نظام التراجع والتقدم (Undo / Redo)**: دعم اختصارات لوحة المفاتيح `Ctrl + Z` و `Ctrl + Y` مع أزرار مباشرة في شريط الأدوات.
- **صانع الميداليات ثلاثية الأبعاد (Keychain Maker)**: أكثر من 56 ستايل وشكل للميدالية مع إمكانية كتابة الاسم، تحديد موضع الفتحة، وإضافة التعليقات والرموز.
- **حاسبة تكاليف الطباعة ثلاثية الأبعاد (Print Cost Calculator)**: حساب دقيق لتكلفة الفلمنت، الكهرباء، وهامش الربح لكل مجسم.
- **نظام الحسابات وقاعدة البيانات**: تسجيل ودخول، دعم تسجيل الدخول بحساب قوقل (Google Sign-In)، واستعادة كلمة المرور عبر Firebase.
- **لوحة إدارة متكاملة (Admin Dashboard)**:
  - حماية الدخول برمز PIN سري مخصص مع إمكانية تغييره فوراً.
  - إدارة المستخدمين (إضافة رصيد، تصفير، حذف الحساب نهائياً، تعديل الباقة).
  - إنشاء أكواد الخصم وروابط الدعوة مع تحديد نسبة أو قيمة الخصم، وتاريخ البداية والنهاية.
  - إحصائيات مالية ونظام مدفوعات ميسر (Moyasar) مخصص لوثيقة العمل الحر السعودية.
  - شريط إعلاني وترويجي علوي قابل للتعديل المباشر.
- **قسم توثيق بيانات مالك المنصة الرسمي**:
  - حفظ رقم وثيقة العمل الحر / السجل التجاري ورابط التحقق المباشر من منصة العمل الحر (freelancing.sa).
  - الحسابات البنكية المعتمدة، رقم الآيبان الدولي (IBAN)، ونسخ الآيبان بنقرة واحدة.
  - قنوات الاتصال الرسمية، الواتساب المعتمد، وحسابات التواصل الاجتماعي.
  - شهادة رقمية رسمية قابلة للطباعة والتصدير كـ PDF لإثبات الحقوق والملكية.
- **الشروط والأحكام وسياسة الخصوصية**: صياغة قانونية متكاملة تحمي المنصة وتتوافق مع نظام التجارة الإلكترونية ونظام حماية البيانات الشخصية السعودي (PDPL).
